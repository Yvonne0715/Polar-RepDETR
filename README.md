# Polar-RepDETR
Pseudocode and bearing defect images for Polar-RepDETR.

This repository provides pseudocode and bearing-defect dataset annotations associated with Polar-RepDETR.

## Pseudocode

The pseudocode includes the overall training procedure and four components:

- RepNCSPELAN4 with Coordinate Attention (CA)
- Enhanced Perception and Feature Interaction (EPFI)
- Linear Deformable Convolution (LDConv)
- Wise-Inner-MPDIoU loss

## Dataset Annotations

 **1,530 bearing-defect images**, covering three classes:

- **0:** Abrasion 
- **1:** Groove 
- **2:** Scratch
